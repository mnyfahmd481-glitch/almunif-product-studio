# المنيف – استوديو المنتجات

مشروع أندرويد مستقل لتنظيم صور المنتجات في ألبومات عامة على الهاتف.

## ما الذي تفعله هذه النسخة؟
- اختيار قسم من: العصارات، الأفران، الغسالات، الشاشات، البطاريات، العروض، منتجات جديدة.
- إدخال اسم المنتج.
- اختيار عدة صور من الهاتف.
- نسخ الصور إلى `Pictures/Almunif/القسم/المنتج` عبر MediaStore.
- لا توجد محادثات أو ردود آلية أو اتصال بواتساب.

## فتح وبناء المشروع
1. افتح المجلد في Android Studio (إصدار حديث يدعم Android Gradle Plugin 8.7.3).
2. انتظر Gradle Sync.
3. من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
4. ستجد APK عادةً في `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظة مهمة عن واتساب
الصور تحفظ في MediaStore ضمن مجلدات Pictures العامة، وهذا هو المسار المناسب كي يقرأها تطبيقات المعرض ومنتقي الصور. ظهور الألبومات داخل منتقي واتساب يعتمد على إصدار أندرويد وواتساب وطريقة منتقي الصور المستخدمة؛ لا يمكن ضمان أن يظهر اسم تطبيق مستقل كمصدر داخل واتساب. هذه النسخة لا تراقب الكاميرا في الخلفية ولا تصنف الصور تلقائياً.

## متطلبات البناء
- Android Studio حديث
- JDK 17 أو أحدث
- اتصال إنترنت أول مرة لتنزيل إضافات Gradle وAndroid SDK 35
